# Ikke-publicerede billeder

Disse filer lå i `images/`, men ingen side refererede til dem. De blev flyttet hertil, så de
ikke længere deployes og ikke kan hentes offentligt — intet er slettet.

Flyt en fil tilbage til den tilsvarende mappe under `images/`, når den skal bruges.
`soho.png` hører til SOHO-casen og skal bruges igen, når den case skrives.

Flyttet 13. oktober 2026.
